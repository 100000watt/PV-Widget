# PV Widget

Widget fotovoltaico off-grid per Windows, con dati ricevuti via MQTT.

## Requisiti

- Windows 10 o Windows 11 a 64 bit.
- Un broker MQTT raggiungibile
- 
## Installazione

1. Scarica `PVWidget_Setup_v1.0.1_Windows_x64.exe` dalla sezione **Assets** della release.
3. Esegui l'installer e completa la procedura guidata.
4. Al termine apri il configuratore e inserisci broker, credenziali e topic MQTT.

L'installer può creare un collegamento sul desktop e abilitare l'avvio automatico con Windows.
